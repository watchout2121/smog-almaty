## Принципы и ограничения
- «Мамбетство» звучит только как риторика антагонистов (вице-мэр Сейтов, поначалу Альтаир), и сюжет её опровергает: данные «Ветра» показывают реальные источники смога. Хамство на дорогах показывается как поведение, а не как признак группы людей.
- Все компании и персонажи вымышлены, реальных брендов в игре нет (даже марок машин в тексте). Реальные улицы и места Алматы — можно.
- Личные данные реальных людей в игру не попадают. Из переписок владельца допустимы только безобидные словечки героев («…Мал.», «Вай.» у Альтаира).
- Карта: © участники OpenStreetMap (ODbL) — атрибуция в меню и CREDITS.md обязательна.

## Архитектура (кратко; подробно в CLAUDE.md)
- three.js r128 глобально, без сборщика; `tools/build.py` генерирует `index.html` и офлайн-файл.
- Сцены: `S.*` в `src/art.js` (menu, apartment, tower, crime, mind, station, station_in, bazaar, shop, road, dam_day, medeu, truck, tunnel, booth; старые yurt/yurt_storm не используются), `city`/`city_drive` (`src/city.js`), `orchard`/`orchard_storm` (`src/orchard.js`).
- Управляемые сегменты: гл. 1 квартира (утренние дела), гл. 2 балкон, место преступления (улики), сад Евы, гл. 3 станция «Ледник-2», гл. 4 центр города, гл. 5 вождение через пробку, гл. 6 тоннель водосброса.
- Персонажи: андроиды на X Bot (шейдер по регионам + диод), люди на Ready Player Me (перекраска, волосы, морфы рта), охрана/ГРОМ на Vanguard; анимации X Bot ретаргетятся на RPM (`retarget()`). Облик Альтаира и Никиты-Х — `src/looks.js` (хук `LOOKS.dress`).
- Город строится из `assets/geo/almaty.json` (здания с реальной высотой, дороги, зелень), трафик — модели Kenney Car Kit (CC0), пешеходы — RPM в масках.

## Известные баги и решения
- **Чёрные прямоугольники** на реальных видеокартах: яркие зеркальные блики переполняли half-float кадр (Inf), свечение размазывало Inf/NaN на полэкрана. Исправлено `SanitizeShader` (после рендера и перед свечением), защитой в SSAO и цветокоррекции; стёкла зданий сделаны менее зеркальными. Регрессионный тест: `npm run test:render`.
- Машины не поворачивают на перекрёстках: едут по своей улице и пересоздаются около игрока.
- Альтаир выглядит моложе, чем нужно (базовое лицо RPM молодое). Рубашка с фламинго повторяет крой фрака базовой модели, внизу видно ремень. Очки Никиты плохо видны строго анфас.
- X2 (второй Никита) описан в `LOOK`, но пока не расставлен в сценах.
- Раньше суставы X Bot красились как одежда: код искал меш `Mesh`, а в модели он называется `Beta_Joints`. Исправлено в v3.1.
- Electron: кириллица в `productName` попадала в User-Agent, и все подресурсы `smog://` падали с `ERR_UNEXPECTED`. Имя приложения теперь латиницей.
- Рабочие андроиды ходят только по отрезку туда-обратно (как прохожие); дворник «толкает» тележку обычной анимацией ходьбы.
- Модели машин Kenney низкополигональные, «игрушечные» — кандидат на замену.
- Программный WebGL (swiftshader) в тестах работает 1–5 кадров в секунду, поэтому движение героя в тестах имитируется телепортом.
- Кэш GitHub Pages ~10 минут: `index.html` подключает скрипты с `?v=<хэш содержимого>`.

## Как проект попадал на GitHub (для справки)
- Из облачной среды Cowork github.com недоступен, поэтому пуш шёл из Linux-среды на компьютере владельца через GitHub CLI (авторизация по коду устройства, владелец подтвердил). Отозвать: GitHub → Settings → Applications → GitHub CLI.
- В Claude Code на компьютере владельца достаточно обычного `git push` (Git for Windows + Git Credential Manager) или `gh`.
- С 28.09.2026 на компьютере владельца стоит **переносной Git** в `%LOCALAPPDATA%\Programs\PortableGit` (`cmd\git.exe`, в PATH не прописан). Рабочая копия — `C:\Users\thebo\code\smog-almaty`. Вход в GitHub — через Git Credential Manager (окно «Connect to GitHub» → вход в браузере; владелец входил сам, токен лежит в диспетчере учётных данных Windows). В `.git/config` список `credential.helper` сброшен и оставлен только `manager` — иначе системный `helper-selector` показывает окно выбора. Если вход понадобится снова (фоновая сессия без терминала), запускать `git push` с `GCM_INTERACTIVE=always`.
